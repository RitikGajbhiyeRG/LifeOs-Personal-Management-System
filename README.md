LifeOS
A CRUD-based Personal Management System built with Python and MySQL. It combines Task, Habit, Study, Notes, and Expense Management into one menu-driven application.

Tech Stack
Python · MySQL · SQL · mysql-connector-python · CRUD · Core Python · CLI

#How to Run
Install Python and MySQL.
Start the MySQL Server in the background.
Open the project in VS Code.
Run database.sql in MySQL to create the LifeOS database and tables.
Make sure the MySQL credentials in main.py match your local MySQL setup.
Install the connector if required:
pip install mysql-connector-python
Run the Python file from VS Code:
python main.py
